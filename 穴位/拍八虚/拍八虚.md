“拍八虚”是中医里的一种养生方法，通过拍打人体八个特定的关节褶皱处（即“八虚”），来驱邪扶正、通经活络。



这八个部位是**两侧对称**的：

- **两肘窝**：肘关节内侧。拍这里有助于缓解心烦、失眠、胸闷，疏散肺邪、心邪。

- **两腋窝**：肩关节内侧。拍这里能疏肝理气，缓解两肋胀痛、易怒、乳腺问题。

- **两腹股沟**：大腿根部。拍这里可以改善下焦湿热，对月经不调、痛经及部分男科问题有益。

- **两腘窝** **guó wō**：膝盖后方。膝盖后方正中间的凹陷区域。 拍这里能缓解腰痛、腿麻、膝盖不适，辅助调理膀胱和肾。

**正确操作方法**：  
用**空掌**（手指并拢呈弓形）或**空拳**，由轻到重依次拍打。建议**早晨**进行，每个部位拍打**36下或81下**，感到微微发热即可。


**特别提醒**：

- 力度要**适度**，以舒适为佳，切忌过猛伤及筋肉。
- 有出血倾向、皮肤破损、患重病或处于孕期的女性**不宜**进行。

通常从上到下、先左后右比较符合习惯和气血流向。

拍八虚一般遵循**从上到下**的顺序，同时建议**先左后右**。推荐顺序如下：

1. **两侧肘窝**（左上肢 → 右上肢）

2. **两侧腋窝**（左腋窝 → 右腋窝）

3. **两侧腹股沟**（左侧 → 右侧）

4. **两侧腘窝**（左膝后 → 右膝后）
